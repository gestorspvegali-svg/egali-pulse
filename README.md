# Egali Performance Hub

Crie o layout completo de uma plataforma web moderna de gestão comercial para uma unidade de intercâmbio chamada Egali Vila Mariana.

A plataforma será usada pelo gestor da unidade e pelas consultoras comerciais para acompanhar metas, vendas, pontuação e desempenho.

OBJETIVO

O sistema deve transformar uma planilha de acompanhamento comercial em uma plataforma visual, intuitiva e profissional.

A prioridade é que qualquer consultora consiga entrar e entender rapidamente:

Qual é a minha meta?

Quanto já fiz?

Quanto falta?

Qual percentual da meta já alcancei?

Quantas vendas preciso fazer?

Estou no ritmo para bater a meta?

Onde preciso melhorar?

O gestor deve conseguir visualizar tanto o desempenho individual quanto o desempenho geral da unidade.

ESTILO VISUAL

Criar um design premium, moderno e corporativo, mas sem parecer um sistema bancário ou excessivamente formal.

Referências de estilo:

Dashboard SaaS moderno

Interface limpa

Visual elegante

Muito espaço em branco

Cards com informações importantes

Gráficos simples e fáceis de interpretar

Navegação lateral

Tipografia moderna

Bordas levemente arredondadas

Sombras muito sutis

Ícones minimalistas

Utilizar uma identidade visual inspirada na Egali, mas sem exagerar no uso de cores.

A interface deve ser predominantemente clara, com fundo neutro e destaque visual para indicadores importantes.

EXPERIÊNCIA

A plataforma deve passar a sensação de:

"Eu entro aqui e sei exatamente onde estou na minha meta."

Evitar excesso de informações.

Priorizar números grandes, gráficos simples e mensagens acionáveis.

O dashboard não deve parecer uma planilha.

Quero que pareça um produto SaaS profissional de gestão comercial, moderno e intuitivo.

Crie primeiro toda a estrutura visual e navegação da aplicação utilizando dados fictícios. Não criar integração com sistemas externos nesta etapa.
